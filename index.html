Servidor Gratuito GitHub & Opciones de Almacenamiento

¿Cómo funciona el almacenamiento de fotos en GitHub Pages?

🚀 1. Despliegue 100% Gratuito en GitHub Pages

Esta página web está diseñada con HTML5, CSS3 y JavaScript moderno nativo. Puedes subir esta carpeta a un repositorio en GitHub y activar GitHub Pages con 2 clics.

💾 2. Almacenamiento Local (IndexedDB) Activo

La aplicación utiliza IndexedDB, la base de datos de alta capacidad del navegador. Permite almacenar cientos de fotos en alta resolución en el celular o computador sin gastar datos y sin necesidad de configurar ningún servidor.

Cualquier instructor o evaluador puede pulsar "Descargar Reporte (Excel)" y "Descargar Todas las Fotos (ZIP)" para consolidar las evidencias.

🌐 3. Opcional: Sincronización en la Nube con Google Sheets / Google Drive
